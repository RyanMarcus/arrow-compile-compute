Reproducing these results

From the repository root (requires Rust, LLVM 21 via inkwell, and Python 3):

python3 benches/report.py --run          # run the full suite into an isolated
                                         # Criterion dir and write
                                         # docs/benchmark-results.json
python3 -m http.server -d docs 8321      # view this page at localhost:8321

Each run records its git revision, machine specs, and timestamps in a manifest; --run --bench NAME restricts to one Cargo bench target, and --results DIR re-exports a previously completed run directory without re-benchmarking. Tests: python3 -m pytest benches/test_report.py.
